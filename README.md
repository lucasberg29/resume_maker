## Resume Maker

A desktop application used to handle muiltiple resumes, allowing the user to create tailored resumes for different job applications. 
The application provides a form-based interface for users to input their personal information, work experience, education, and skills. 
Users can then export their resumes in PDF or Word format for easy sharing and printing.

# Features

- **Form-based resume builder** — fill in your personal info, work experience, education, and skills through a clean, structured interface
- **Export to PDF** — generate a print-ready PDF of your resume
- **Export to Word (.docx)** — export an editable Word document for further customization
- **Live preview** — see your resume take shape as you fill in the form

# Tech Stack

- **Language:** C#
- **Framework:** WPF (.NET)
- **UI:** XAML

# Prerequisites

- Windows OS
- Visual Studio 2022 (recommended)

# Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/lucasberg29/resume_maker.git
   ```
2. Open `ResumeMaker.sln` in Visual Studio
3. Restore NuGet packages (Visual Studio usually does this automatically)
4. Build and run the project (`F5`)

# Usage

1. Launch the application
2. Click on **New Resume** to start creating a new resume
3. Fill in your details across the form sections:
   - Personal Information (name, email, phone, location)
   - Technical Skills
   - Experience
   - Education
   - Other Experience
4. Click in the Resume tab **Export to PDF** or **Export to Word** to save your resume
